# ใส่รูปคู่ตรงนี้ 📸

ตั้งชื่อไฟล์ให้ตรงตามนี้ (.jpg) แล้วรูปจะขึ้นบนเว็บเอง
ถ้ายังไม่มีไฟล์ไหน เว็บจะขึ้นกรอบหัวใจสีชมพูพร้อมชื่อไฟล์แทน

| ไฟล์ | อยู่ตรงไหน |
|---|---|
| `cover.jpg` | รูปในกรอบหัวใจลูกไม้ บนการ์ดในซองจดหมาย |
| `strip-1.jpg`, `strip-2.jpg`, `strip-3.jpg` | ฟิล์ม 3 ช่อง หน้านับเวลา |
| `taipei.jpg`, `chengdu.jpg`, `shanghai.jpg`, `seoul.jpg` | แสตมป์ + โพลารอยด์บนแผนที่ |

ไฟล์ไม่ควรใหญ่เกิน ~500KB ต่อรูป (ย่อเหลือด้านยาว ~1200px) เว็บจะได้โหลดเร็ว

เพลง (ไม่บังคับ): ใส่ไฟล์ `music/our-song.mp3` แล้วจะมีแผ่นเสียงมุมซ้ายล่างให้กดเล่น
